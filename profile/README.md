## Scope

This organization hosts code, data, and documentation supporting internal processes that require collaboration across the WADOH AMD team network (PHL, DIQA, MEP). If a project is developed, reviewed, maintained, or required by more than one team for internal operations, it belongs here.

Public-facing work, and work tied exclusively to a PGCoE project, belongs in the [Northwest Pathogen Genomics Center of Excellence](https://github.com/nw-page) organization. Work that stays entirely within a single team's internal workflow generally belongs in that team's own space.
